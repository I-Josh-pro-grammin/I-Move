✅ IMove – Ride-Sharing App (MVP)

IMove is a simplified ride-sharing mobile application that connects passengers and riders.
The MVP focuses on showing the main flow of requesting a ride and accepting a ride

✅ Features
Passenger

Select pickup location (map or input)

Select destination

View fare estimate

View nearby riders (mock or basic backend)

Choose rider

Request ride

See ride acceptance or decline

Rider

View incoming ride requests

View passenger details

Accept or decline a request

Basic profile screen

Shared

Register + Login (email/password)

Role selection (Passenger or Rider)

Role-based navigation

Simple profile screen

✅ Ride Flow (Simplified)

Passenger chooses pickup + destination

Passenger sees nearby riders

Passenger chooses a rider and requests a ride

Rider sees the incoming request

Rider accepts or declines

Passenger sees the result
